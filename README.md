# WOOJIN LEE — Frontend Engineer Portfolio

Personal portfolio site built with React, TypeScript, and Vite.

🔗 [portfolio.ieeooii.com](https://portfolio.ieeooii.com)

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Build**: Vite
- **Styling**: Vanilla Extract (zero-runtime CSS-in-JS)
- **Routing**: Wouter
- **i18n**: Custom hook (ko / en)
- **Markdown**: react-markdown + remark-gfm + rehype-raw

## Features

- Bilingual support (Korean / English)
- Project portfolio with category filter & search
- Project detail pages with prev/next navigation
- Responsive layout
- OG image & meta tags

## Dev

```bash
pnpm install
pnpm dev
pnpm build
```
