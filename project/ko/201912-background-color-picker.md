## 소개

3D 의류 뷰어에서 배경색을 Preset(미리 정의된 배경) / Custom Color(사용자 직접 등록) 두 모드로 커스터마이징하는 기능이다. 색상 선택 시 3D 뷰어에 실시간 미리보기가 반영되어야 하고, 여러 UI 진입점에서 동일한 색상 상태를 참조해야 하는 구조적 요구사항이 있었다. 입사 후 MobX 스토어를 처음으로 직접 주도 설계한 기능이다.

## 주요 구현

### MobX 단일 스토어 설계 & Canvas API 브리지

- **Problem**: 색상 상태가 뷰어 툴바·렌더 설정·스페이스 생성 모달 세 곳에서 각각 복사·관리되고 있어, 한 곳에서 변경해도 나머지에 반영되지 않는 동기화 불일치가 발생했다. 또한 피커 드래그 중 3D 뷰어 배경이 실시간으로 갱신되어야 했는데, 이를 위해 React 상태 변경과 Canvas API 호출이 동시에 이루어지는 구조가 필요했다.
- **Solve**: 색상 목록·현재 선택 색상·피커 커서 색상을 MobX `@observable`로 단일 스토어에 집중하여 세 곳이 동일한 출처를 참조하도록 구조화. `react-color`의 `onChange`(드래그 중 실시간)와 `onChangeComplete`(선택 완료)를 분리하여 — 드래그 중에는 Canvas 배경 변경 API만 호출해 뷰어를 즉시 갱신하고, 선택 완료 시에만 스토어 상태를 확정. 직전에 포토 배경이 설정되어 있는 상태에서 색상 피커를 조작하면 자동으로 배경을 초기화한 뒤 색상으로 전환. 최근 배경 설정은 아이템별로 localStorage에 저장하여 페이지 재방문 시 복원.
- **Result**: 세 컴포넌트가 동일한 스토어를 참조하여 상태 동기화 문제 해소, 색상 피커 드래그 시 3D 뷰어 배경이 지연 없이 실시간 미리보기

### Custom Color CRUD + 중복 방지 & 인터랙션 처리

- **Problem**: 커스텀 색상 추가 시 API 응답 전에 add 버튼을 중복 클릭하면 동일 색상이 여러 번 등록되는 문제가 있었다. 삭제 시 500 에러가 발생하는 케이스가 존재했으며, ESC 키·외부 클릭으로 팝업을 닫는 인터랙션도 처리되지 않은 상태였다. 또한 색상 피커 내부에서 키보드 입력이 뷰어 단축키로 전파되는 문제도 있었다.
- **Solve**: `@computed`로 현재 색상이 목록에 이미 존재하는지 여부를 파생하고, 이를 기반으로 추가 버튼 비활성화 조건을 계산하여 UI 레벨에서 차단 — API 호출 전 스토어 레벨에서도 중복 체크를 한 번 더 수행하여 이중 방어. 최대 등록 수 초과 시에도 동일하게 버튼 비활성화. 삭제는 API 응답 전 로컬 배열에서 먼저 제거하는 낙관적 업데이트로 체감 응답성 향상. ESC 키·외부 클릭 감지는 전용 훅으로 통합 처리. 피커 컨테이너의 `keydown` 이벤트에 `stopPropagation`을 걸어 뷰어 단축키 전파 차단.
- **Result**: 중복 등록 방지 및 키보드 접근성 확보, 뷰어 단축키 충돌 해소, 삭제 응답성 개선

### 컴포넌트 아키텍처 분리

- **Problem**: ColorPicker 컴포넌트가 특정 페이지 내부에 강하게 결합되어 있어, 렌더 설정·스페이스 생성 모달 등 다른 사용처에서 재사용하려면 코드를 복사해야 했다. 다국어 적용도 각 사용처마다 따로 처리해야 해서 누락 위험이 있었다.
- **Solve**: ColorPicker를 독립 컴포넌트로 추출하고, 각 사용처는 필요한 props만 전달하는 구조로 분리. 다국어 키도 공통화하여 일괄 적용.
- **Result**: 코드 중복 제거, 다국어 일괄 적용 완료, 이후 새로운 사용처 추가 시 컴포넌트만 가져다 쓰는 구조 확립

## 회고

"상태를 어디에 두어야 하는가"라는 질문에 대해, 여러 컴포넌트가 하나의 상태를 공유해야 할 때 각 컴포넌트에 상태를 복사하는 것이 아니라 단일 출처(single source of truth)로 끌어올려야 한다는 것을 체감한 계기가 됐다. 또한 `onChange`(실시간)와 `onChangeComplete`(확정)를 분리하는 패턴은 이후 다른 실시간 인터랙션 구현에서도 반복적으로 활용하게 된 원칙이 됐다.
